Как установить

Windows

  1. Скачай SigmaLauncher-portable.exe по кнопке выше.
  2. Запусти файл. Если появится синее окно Windows — нажми «Подробнее», потом «Выполнить в любом случае». Это нужно только один раз.
  3. Введи ник, выбери версию и нажми «Играть».

Обновления приходят сами: в лаунчере появится кнопка «Обновить».

Android

  1. Открой эту страницу на телефоне и скачай SigmaLauncher.apk.
  2. Открой файл и разреши установку из этого источника.
  3. Выбери сервер и нажми «Играть» — Minecraft откроется и подключится сам.

На телефоне работает Bedrock-версия: нужен Minecraft из Google Play.
