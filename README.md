# Sigma Launcher

Minecraft-лаунчер: все версии, офлайн-вход по нику, автоскачивание Java, свой скин, автообновления.

**Скачать:** [последняя версия](https://github.com/0504405151d-hue/sigma-launcher/releases/latest/download/SigmaLauncher-portable.exe) — просто запусти exe.

Каждый push в `main` автоматически собирает новый exe и выпускает релиз — у всех игроков появляется кнопка «Обновить».

Разработка: `npm install`, `npm start`.
